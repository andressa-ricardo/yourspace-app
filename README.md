# yourspace-app

Base inicial do app `yourspace` com Expo Router + NativeWind.

## Rodar o projeto

```bash
npm install
npx expo start --clear
```

## Estrutura atual

- `app/_layout.tsx`: layout raiz do Expo Router
- `app/index.tsx`: tela inicial limpa usando NativeWind
- `components/ui/app-icon.tsx`: mapa centralizado de icones Lucide
- `tailwind.config.js`: configuracao do Tailwind/NativeWind
- `global.css`: entrada das diretivas Tailwind
